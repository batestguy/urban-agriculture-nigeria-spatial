## Traps that cost real time this session

- **`compatibilityMode 14` (Word 2010) in every rendered docx.** Quarto/pandoc writes it, and
  `reference.docx` carries `Application: Microsoft Macintosh Word`. Word opens the file in
  [Compatibility Mode]. Fixed by the new `scripts/normalize_docx_meta.py`, which sets mode 15 and
  normalises app metadata. **Run it after `fix_docx_trp.py` on every render.**
- **The T&F submission portal rejects hyphens in uploaded filenames** — "Include alphanumeric
  characters or underscores only." Hence `manuscript_anonymised.docx`. The repo file keeps its
  hyphen; only the upload name changes.
- **The portal's Dropzone input cannot be driven by a file-chooser click.** It is
  `visibility:hidden` and zero-width, and the chrome-devtools MCP is sandboxed to `%TEMP%` for
  reads. Workaround used: base64 the file into a JS source file, reconstruct it in the page as a
  real `File`, attach it via `DataTransfer`, and dispatch `change` **plus** `dragover`/`drop`.
  `.scratch/make_upload_js.py` generates those payloads (`python make_upload_js.py <1|2|3>`).
  **Dispatch the file to ONE input only** — attaching to both dropzones queues it twice and the
  portal rejects it as a duplicate filename.
- **`mat-select` dropdowns need a real click, not keyboard.** `Home`/`ArrowDown`/`Enter` landed on
  "Author Bio" twice. Open the overlay and click the matching `mat-option` by text instead.
- **The portal requires both PDF proofs to be viewed** before Submit enables. Clicking both
  preview buttons is enough; the blob tabs need not be read.
- **`.scratch/` is gitignored and the identity gate scans absolute paths.** Throwaway probes go
  there and stay free of absolute paths, or get deleted.
