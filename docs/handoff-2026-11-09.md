## Rebuild order — do not reorder

```
cd manuscript && quarto render manuscript.qmd          # html + pdf + docx
cd manuscript && quarto render supplementary.qmd       # supplementary.docx
python scripts/fix_docx_trp.py --anonymise             # typography, author block, review copy

```

**Re-rendering alone silently drops the author block and the compatibility fix.** Rendering
overwrites both DOCX files, and `fix_docx_trp.py` must be re-run after every render. Then re-run
the four gates above.

`scripts/fix_docx_format.py`, `fix_docx_ajlpgs.py` and `trp-harvard.csl` belong to abandoned
specs. `fix_docx_trp.py` is the one to use despite its name — TNR 12 pt single-spaced, which is
what the current output requires.

## Traps that cost real time

- **`compatibilityMode 14`** — Quarto writes Word 2010 mode on every render and `reference.docx`
  carries a Mac Word 2010 stamp, so Word opens in [Compatibility Mode]. `normalize_docx_meta.py`
  fixes it; it is not a file-format fault, and layout does not change (D-14).
- **The portal's Dropzone cannot be driven by a file-chooser click.** The input is
  `visibility:hidden` and zero-width, and the chrome-devtools MCP can only read from `%TEMP%`. The
  workaround: base64 the file into a JS source file, rebuild it in the page as a real `File`,
  attach via `DataTransfer`, and dispatch `change` **plus** `dragover`/`drop`. Generator:
  `.scratch/make_upload_js.py` (`python make_upload_js.py <1|2|3>`). **Attach to ONE input only** —
  dispatching to both dropzones queues the file twice and the portal rejects the duplicate name.
- **`mat-select` dropdowns need an overlay click, not keyboard.** `Home`/`ArrowDown`/`Enter` landed
  on "Author Bio" twice. Open the overlay and click the matching `mat-option` by text.
- **Both PDF proofs must be viewed** before Submit enables. Clicking both preview buttons is
  enough; the blob tabs need not be read.
- **`Rscript build.R --audit` asserts what the prose must say.** Keep *"66 per cent per doubling"*,
  *I = 0.300*, *ρ = 0.613*, *ΔAIC = 20.0*, *19 of 775*, *8.9%* verbatim. Editing prose to satisfy a
  test is the wrong direction.
- **`verify_author_block.py` scans every text file for the old folder name.** Write throwaway probes
  to `.scratch/` (gitignored) and keep them free of absolute paths — a scratch script with a
  hardcoded path trips the identity gate.
- **The portal's filename and the repo's filename differ.** Do not "fix" the underscore locally;
  it is only an upload constraint.
- **This shell rejects some command shapes** — inline Python with quotes/regex splits badly. Write
  a `.py` file and run it.
