## Environment traps that cost time

- **`Rscript build.R --audit` asserts what the prose must say.** Rewriting "66 % per doubling"
  as "two-thirds per doubling" fails the gate. That is the gate working: restore the phrase, do
  not edit the test.
- **Editing a `.qmd` without re-rendering fails `verify_author_block.py`** — the old rendered
  output still carries the previous content. Re-render, then re-run `fix_docx_trp.py`.
- **`fix_docx_trp.py` must be re-run after every render**; rendering overwrites the docx.
- **This shell rejects some command shapes** (chained `;` with `Select-Object`, inline Python
  with quotes/regex). Prefer single commands, or write a `.py` file and run it.
- **pandoc lowercases BibTeX titles** unless brace-protected. `scripts/build_bib.py` now
  protects proper nouns word by word; without it "Ghana" renders as "ghana".
